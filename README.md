# Laboratorio 6 - Bases de Datos: Sistema de Reservas de Hotel

## Descripción de la práctica
Para este laboratorio se ha definido como solución a un problema real un Sistema de Reservas en un Hotel. Este proyecto implementa el modelo físico en PostgreSQL utilizando Supabase en la nube.

## Modelo Lógico (DER)
El modelo incluye las siguientes tablas:
- `users` (Huéspedes)
- `rooms` (Habitaciones)
- `reservations` (Reservas)
- `reservations_rooms` (Tabla intermedia de relación N:M)
